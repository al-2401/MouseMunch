# MouseMunch

Маленькая аркадная игра на Flutter для Android: по полу разбросаны крошки,
мышка бегает от крошки к крошке и съедает их.

## Как играть

* **Кормушка** в правом верхнем углу. Нажатие на неё проигрывает анимацию
  нажатия, звук и высыпает на пол порцию крошек — они разлетаются по экрану с
  анимацией падения.
* **Мышка** сама выбирает ближайшую крошку, разворачивается к ней головой и
  бежит (анимация бега + звук шагов). Добежав, ненадолго останавливается и ест
  (анимация жевания + хруст), после чего крошка исчезает с экрана.
* **Нажатие на мышку** во время бега или еды прерывает её: мышка останавливается,
  пищит и вырывается — играет анимация борьбы.
* Когда крошек на полу не остаётся, мышка останавливается и переходит в
  **анимацию ожидания**: дышит, шевелит хвостом, подёргивает ушами и моргает.

## Настройки

Кнопка настроек — в левом верхнем углу. Все изменения применяются сразу:

| Параметр | Диапазон | Что делает |
| --- | --- | --- |
| Количество крошек | 1–40 | сколько крошек высыпается за одно нажатие на кормушку |
| Скорость мышки | 20–420 px/с | скорость бега (от неё же зависит частота шагов) |
| Скорость поедания | 0.2–4.0 крош./с | сколько мышка возится с одной крошкой |
| Звук | вкл/выкл | все звуки игры |

Там же есть кнопка «Убрать крошки с пола».

## Звуки

Все звуки синтезированы скриптом и лежат в `assets/audio`:
`move.wav` (шаги, играет в цикле во время бега), `eat.wav` (хруст),
`squeak.wav` (писк), `pour.wav` (сыплются крошки), `tap.wav` (нажатие на
кормушку), `ui.wav` (щелчок в меню).

## Сборка

```bash
flutter pub get
flutter run                 # на подключённом устройстве или эмуляторе
flutter build apk --release # готовый APK
```

Нужен Flutter 3.29+ и JDK 17+ (проверено на Flutter 3.47.5 / Dart 3.13.4,
JDK 21). Папка `android/` — стандартный шаблон `flutter create` (AGP 9.1,
Kotlin 2.4, Gradle 9.3) с заменённой иконкой, названием и цветом заставки.
Gradle wrapper (`gradlew`, `gradle-wrapper.jar`) в репозиторий не коммитится —
Flutter подкладывает его при первой сборке.

Релизная сборка подписана отладочным ключом, чтобы `flutter build apk` работал
сразу; перед публикацией замените `signingConfig` в
`android/app/build.gradle.kts` на настоящий ключ.

## Тесты

```bash
flutter test
```

`flutter analyze` проходит без замечаний, все 7 тестов зелёные.
`test/game_controller_test.dart` гоняет симуляцию без звука: проверяет, что
крошки ложатся в пределах поля и мимо кормушки, что мышка добегает, съедает и
переходит в ожидание, что во время бега она повёрнута головой к цели и что
нажатие прерывает её.

## Структура

```
lib/
  main.dart                 точка входа
  game/game_settings.dart   настройки (количество крошек, скорости, звук)
  game/crumb.dart           крошка и её анимация падения
  game/game_controller.dart состояния мышки и вся логика игры
  audio/sound_manager.dart  проигрывание звуков
  ui/game_screen.dart       экран, игровой цикл (Ticker), HUD
  ui/mouse_view.dart        отрисовка мышки и четыре её анимации
  ui/crumb_view.dart        отрисовка крошек
  ui/feeder_view.dart       кормушка и анимация нажатия
  ui/settings_sheet.dart    шторка настроек
tool/
  generate_sounds.py        генерация assets/audio
  generate_icons.py         генерация иконок запуска
```

Ассеты пересобираются так:

```bash
python3 tool/generate_sounds.py
python3 tool/generate_icons.py
```
